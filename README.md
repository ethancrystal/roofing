# Northline Roofing Co. concept

A premium, responsive one-page website concept for a professional roofing company. The visual
identity is original; the supplied reference sites informed only the information hierarchy,
trust-building patterns, service presentation, and conversion strategy.

## Preview locally

```bash
python3 -m http.server 4173
```

Open [http://localhost:4173](http://localhost:4173).

## Project files

- `index.html` — semantic page content and lead form
- `styles.css` — visual system and responsive layouts
- `script.js` — mobile navigation, section state, FAQ, reveals, and form preview behavior

## Required before launch

The repository only confirmed that the client is a roofing company. Replace every bracketed
placeholder with verified client information:

- Company name and final brand assets
- Phone, email, address, and business hours
- Exact service list and service descriptions
- Service area
- License and insurance status
- Warranty and ownership details
- Differentiators and featured-service benefits
- Project types, locations, and approved project photography
- Real customer testimonial and attribution
- Client-approved FAQ answers

Connect the estimate form to the client’s chosen CRM or form endpoint, and replace the concept
photography with licensed client images before production.
